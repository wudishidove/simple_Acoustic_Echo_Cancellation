# Echo Mic 回音消除麥克風

降低喇叭聲音被麥克風再次收錄的回音，供 Discord、OBS、遊戲語音等軟體使用。

**支援 Windows 10 / 11 x64，不需要安裝 Python。**

[下載免安裝版](https://github.com/wudishidove/simple_Acoustic_Echo_Cancellation/releases/latest/download/EchoMic-Windows-x64.zip) · [查看所有版本](https://github.com/wudishidove/simple_Acoustic_Echo_Cancellation/releases)

## 安裝

1. 下載 `EchoMic-Windows-x64.zip`，完整解壓縮到「文件」等可寫入的資料夾。
2. 開啟資料夾中的 `EchoMic.exe`。請保留整個資料夾，不能只複製 EXE。
3. 首次使用時，在「音訊裝置」按「安裝虛擬裝置…」，允許 Windows 管理員授權，依提示完成 **VB-Audio Hi-Fi Cable & ASIO Bridge** 安裝。
4. 如果安裝程式要求重新啟動電腦，請先重開機，再開啟 Echo Mic。

虛擬裝置只需安裝一次，會新增獨立的音訊裝置，不影響原有 VB-CABLE。

## 開始使用

在「音訊裝置」按「重新整理裝置」，依序選擇：

| 設定 | 選擇的裝置 |
| --- | --- |
| 你的麥克風 | 平常使用的實體麥克風 |
| 正在發聲的喇叭 | 實際播放聲音的喇叭，可複選 |
| 處理後的輸出 | **Hi-Fi Cable Input** |

按下「啟動回音消除」，再到 Discord、OBS 或遊戲的音訊設定，將麥克風改成 **Hi-Fi Cable Output (VB-Audio Hi-Fi Cable)**。

Windows 的預設播放裝置維持平常的實體喇叭。**使用期間請讓 Echo Mic 保持執行**；停止或結束程式後，虛擬麥克風就不會收到聲音。

## 音效調整與校正

在「音效與校正」可調整麥克風音量、背景降噪與回音延遲。建議先使用預設的 **40 ms**，變更後重新啟動回音消除。

需要自動校正時：

1. 在「音訊裝置」選好麥克風，並只勾選一個要校正的喇叭。
2. 到「音效與校正」按「校正延遲（約 25 秒）」。
3. 校正會暫停麥克風輸出並播放測試語音，請保持安靜，不要調整喇叭音量。
4. 完成後查看畫面上的結果。效果沒有明確改善時會保留原設定；若取消校正，請手動重新啟動回音消除。

## 日常使用

- **縮到系統匣**：預設按視窗右上角 X，程式仍會在右下角系統匣繼續運作。可在「一般設定」更改此行為。
- **開機自動啟動**：在「一般設定」開啟，登入 Windows 後會使用上次儲存的設定。第一次請先成功啟動一次回音消除。
- **結束程式**：在系統匣圖示按右鍵，選「結束 Echo Mic」。
- **更新版本**：先結束舊程式，再用新版檔案更新。保留原本的 `settings.json` 可沿用設定；若移動程式位置，請將開機自動啟動關閉再開啟一次。

## 常見問題

- **找不到 Hi-Fi Cable**：確認已安裝虛擬裝置，必要時重開機，再按「重新整理裝置」。
- **通話軟體沒有聲音**：確認 Echo Mic 已啟動回音消除，且通話軟體選的是 **Hi-Fi Cable Output**。
- **虛擬裝置無法啟動**：在 Windows 音效控制台，確認 Hi-Fi Cable Input 與 Output 的預設取樣率相同，建議都設為 **48000 Hz**。
- **仍有回音**：確認所有實際發聲的喇叭都已勾選，再嘗試校正。回音消除效果也會受喇叭音量與房間環境影響。
- **更換麥克風或喇叭**：先停止回音消除，重新整理並選好裝置，再啟動。

音訊只在本機處理，不儲存錄音，也不上傳。
